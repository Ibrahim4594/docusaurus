Docusaurus CLI

Docusaurus includes a powerful set of command-line tools that help you generate, develop, and deploy your site efficiently.

After bootstrapping your project, these scripts become available through your package manager:

package.json scripts:

"docusaurus": "docusaurus"
"start": "docusaurus start"
"build": "docusaurus build"
"swizzle": "docusaurus swizzle"
"deploy": "docusaurus deploy"
"clear": "docusaurus clear"
"serve": "docusaurus serve"
"write-translations": "docusaurus write-translations"
"write-heading-ids": "docusaurus write-heading-ids"

CLI Commands Overview

Below is a comprehensive list of Docusaurus CLI commands and their usage details.

docusaurus start [siteDir]

Starts a local development server using Webpack Dev Server and automatically rebuilds your site when files change.

Options

--port (default: 3000): Port for the dev server
--host (default: localhost): Use 0.0.0.0 for external access
--locale: Serve in a specific locale
--hot-only (default: false): Enables HMR without fallback
--no-open (default: false): Prevents auto-opening the browser
--config: Path to custom docusaurus.config.js
--poll [ms]: Enables polling mode
--no-minify: Disable JS/CSS minification

Some features during development behave differently than production (example: anchor links).

Development Over Network

To run Docusaurus on remote servers or GitHub Codespaces:

npm run start -- --host 0.0.0.0

Enabling HTTPS with mkcert

Generate certificates:
mkcert localhost
Produces: localhost.pem and localhost-key.pem

Install certificate:
mkcert -install

Start dev server with HTTPS:
HTTPS=true SSL_CRT_FILE=localhost.pem SSL_KEY_FILE=localhost-key.pem yarn start

Open https://localhost:3000/

docusaurus build [siteDir]

Builds an optimized production version of your site.

Options

--dev: Build in dev mode
--bundle-analyzer: Analyze bundles
--out-dir (default: build): Custom output folder
--config: Custom config path
--locale: Build for a specific locale
--no-minify: Skip JS/CSS minification

If CSS breaks because of advanced minification:

USE_SIMPLE_CSS_MINIFIER=true
To skip HTML minification: SKIP_HTML_MINIFICATION=true

docusaurus swizzle [themeName] [componentName] [siteDir]

Customize Docusaurus theme components.

Example

npm run swizzle @docusaurus/theme-classic Footer -- --eject

Options

themeName: Theme to swizzle
componentName: Component to modify
--list: Show all swizzlable components
--eject: Fully eject the component
--wrap: Wrap component
--danger: Allow unsafe components
--typescript: Use TypeScript version
--config: Custom config path

Unsafe components can break due to internal changes.

docusaurus deploy [siteDir]

Deploys your Docusaurus site, usually to GitHub Pages.

Options

--locale: Deploy specific locale
--out-dir (default: build): Build directory
--skip-build (default: false): Deploy without rebuilding
--target-dir (default: .): Target directory
--config: Custom config path

docusaurus serve [siteDir]

Serves the production build locally.

Options

--port (default: 3000)
--dir (default: build)
--build (default: false): Build before serving
--config: Custom config
--host (default: localhost)
--no-open: Do not open browser automatically

docusaurus clear [siteDir]

Clears caches, generated files, and build artifacts.
Useful for debugging or after upgrades.

docusaurus write-translations [siteDir]

Generates translation JSON files for internationalization.

Options

--locale (default: project default locale)
--override (default: false): Overwrite existing translations
--config: Custom config path
--messagePrefix: Add prefix to translation strings

docusaurus write-heading-ids [siteDir] [files]

Adds consistent heading IDs to all Markdown headings.

Options

files: Markdown files to process
--maintain-case (default: false): Keep original heading case
--overwrite (default: false): Overwrite existing IDs
